# phonecard · 手机桌面卡片

一个 APK 里可以装多张 Android 桌面卡片（标准 AppWidget）。应用名：**手机桌面卡片**。

| 卡片 | 显示名（选择列表里） | 说明 |
| --- | --- | --- |
| 01 | `手机桌面卡片-白色时钟` | 仿一加桌面大时钟：日期 + 超大时间，数字全白，不显示天气，透明背景 |

## 下载

到 **[Releases](https://github.com/zhuweiyou/phonecard/releases/latest)** 下载最新版本的 `phonecard-vX.Y.Z.apk`，安装即可。Releases 里的是已经签好名的 APK，无需自己编译。

## 使用方法

### 安装

1. 下载 `phonecard-vX.Y.Z.apk`；
2. 点击安装，首次需允许「安装未知来源应用」。

### 添加到桌面

1. 长按桌面空白处（或双指捏合）→ 进入编辑模式；
2. 点「卡片」→ 在「卡片中心」滑到最底部 → 点「插件」；
3. 列表里找 `手机桌面卡片-白色时钟` → 点一下即添加到当前页；
4. 长按一加自带的时钟卡片 → 「移除插件」，删掉原卡片。

> 注意：「卡片中心」首页那些是 OPPO 自家系统卡片，第三方进不去；第三方卡片都在最底部的「插件」列表里。

### 交互

- 点**日期 / 星期** → 打开系统日历；
- 点**时间** → 打开系统时钟。
